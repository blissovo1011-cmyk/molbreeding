# MRD - 市场需求文档

## MolBreeding 试剂产品中心

### 1. 项目背景

MolBreeding（分子繁殖）是一家专注于分子育种领域的企业，核心业务涉及基因检测产品和配套试剂的研发、生产与销售。随着业务规模扩大，公司需要一套统一的主数据管理系统来管理产品和试剂信息，并支持向大陆和海外两个业务系统（MIMS）同步数据。

### 2. 市场痛点

- 产品和试剂信息分散在多个系统中，缺乏统一管理入口
- 产品上下架流程缺少系统化支持，依赖人工操作容易出错
- 大陆和海外业务系统的数据同步依赖手动维护，效率低且易出现数据不一致
- 试剂库存信息分散在各仓库系统中，无法集中查看
- 产品和试剂的生命周期管理（待定→在售→下架）缺乏可视化追踪

### 3. 目标用户

- 产品经理：管理产品全生命周期，配置产品参数
- 试剂管理员：管理试剂信息，关联检测产品，配置库房
- 业务运营：查看大陆/海外 MIMS 的产品和试剂在售情况
- 管理层：了解产品和试剂的整体状态分布

### 4. 核心价值主张

- 一个平台统一管理所有检测产品和配套试剂
- 产品和试剂的全生命周期可视化管理（待定→在售→下架）
- 一键同步产品/试剂到大陆和海外业务系统，支持独立上下架
- 多仓库试剂库存信息集中展示
- 数据持久化存储，支持在线访问

### 5. 竞品分析

当前市场上缺乏针对分子育种行业的专业产品试剂管理系统，大多数企业使用通用 ERP 或 Excel 管理，存在以下不足：
- 无法支持基因组相关的专业字段（SNP位点数、参考基因组等）
- 不支持多区域业务系统的数据同步
- 缺乏试剂与产品的关联管理

### 6. 成功指标

- 产品和试剂数据录入效率提升 50%
- 大陆/海外数据同步从手动操作变为系统化一键同步
- 产品上下架流程从线下审批变为线上流转
- 系统可用性 > 99%
