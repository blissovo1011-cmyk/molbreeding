# PRD - 产品需求文档

## MolBreeding 试剂产品中心 V1.0

### 1. 产品概述

MolBreeding 试剂产品中心是一个面向分子育种行业的全局主数据管理系统，包含三个核心模块：产品试剂中心（读写）、大陆 MIMS（只读）、海外 MIMS（只读）。系统支持产品和试剂的全生命周期管理、多区域同步配置和库存信息查看。

### 2. 系统架构

- 前端：React + Ant Design + TailwindCSS
- 后端：Express + TypeScript + PostgreSQL
- 部署：Railway（前后端一体化部署）

### 3. 功能模块

#### 3.1 产品试剂中心

##### 3.1.1 产品管理

**产品列表**
- 展示所有产品，支持按类别筛选（全部/自主研发/定制开发）
- 列表按创建时间倒序排列
- 支持自定义列显示和列固定（左固定/右固定）
- 文本过长时省略号显示，鼠标悬浮查看全部
- 展开行显示"在售区域"，展示已同步的子系统信息

**产品字段**
- 必填字段：产品编号（唯一）、产品类别（自主研发/定制开发）、产品类型、产品技术（GenoBaits®/GenoPlexs®）、物种、试剂预警值
- 可选字段：产品版本、产品名称（中/英）、项目编号、客户单位、客户姓名、可选结果交付形式
- 基因组字段：数据量标准、区段数、核心SNP位点数、mSNP位点数、InDel数、目标区域数、参考基因组等 30+ 个专业字段
- 布尔字段：配置finalreport、位点信息是否保密、升级后能否再生产为新版本

**产品 CRUD**
- 新增产品：填写表单，初始状态为"待定"
- 编辑产品：修改产品信息
- 查看详情：弹窗展示完整产品信息
- 删除产品：确认后删除，级联删除关联的试剂和在售区域数据

**产品状态流转**
- 待定 → 在售：申请上架审批，需填写转产信息，可同时配置同步到大陆/海外 MIMS
- 下架 → 在售：支持重新上架
- 在售 → 下架：申请下架审批，需填写下架原因，大陆/海外 MIMS 同步下架
- 已在售的产品不可重复上架

**产品同步配置**
- 支持同步到大陆 MIMS 和/或海外 MIMS
- 同步时需配置对应子系统的试剂预警值
- 首次同步时，子系统状态继承产品主状态

**子系统独立上下架**
- 大陆 MIMS 和海外 MIMS 可独立控制产品的上下架状态
- 在售区域展示各子系统的同步状态、预警值和产品状态
- 支持子系统独立上架和下架操作

##### 3.1.2 试剂管理

**试剂列表**
- 展示所有试剂，包含库存信息
- 列表按创建时间倒序排列
- 支持自定义列显示和列固定
- 展开行显示"在售区域"

**试剂字段**
- 必填字段：分类（Panel类/建库类/定量类/提取类/单位点检测类/SSR检测类/其它）、名称、关联检测产品（仅限已生效产品）、规格
- 库房配置：支持多个库房，每个库房包含库房名称、货号、金蝶物料编码

**试剂 CRUD**
- 新增试剂：填写表单，选择关联产品（仅限在售产品），配置库房信息，初始状态为"待定"
- 编辑试剂：修改试剂信息和库房配置
- 查看详情：弹窗展示完整试剂信息
- 删除试剂：确认后删除，级联删除在售区域数据

**试剂状态流转**
- 待定 → 在售：上架操作
- 在售 → 下架：下架操作

**试剂同步配置**
- 支持同步到大陆 MIMS 和/或海外 MIMS
- 大陆同步需配置：预警值
- 海外同步需配置：预警值、英文名称（必填）
- 同步时子系统状态继承试剂主状态

**试剂子系统独立上下架**
- 在售区域展示各子系统的库存信息、预警值、英文名称、试剂状态
- 支持子系统独立上架和下架操作

**库存信息**
- 每个库房显示库房名称、货号、物料编码
- 支持点击"查看库存"加载批次、效期、库存量信息
- 支持收起库存详情

#### 3.2 大陆 MIMS（只读）

- 产品列表：仅展示已同步到大陆的产品，预警值显示大陆配置值
- 试剂列表：仅展示已同步到大陆的试剂，显示大陆同步配置
- 所有数据只读，点击"详情"查看完整信息但不可编辑

#### 3.3 海外 MIMS（只读）

- 产品列表：仅展示已同步到海外的产品，预警值显示海外配置值
- 试剂列表：仅展示已同步到海外的试剂，显示海外同步配置（含英文名称）
- 所有数据只读，点击"详情"查看完整信息但不可编辑

### 4. 交互设计

#### 4.1 导航

- 左侧固定导航栏，包含三个一级菜单：产品试剂中心、大陆 MIMS、海外 MIMS
- 顶部固定面包屑导航
- 内容区域独立滚动

#### 4.2 弹窗

- 所有弹窗垂直居中显示
- 弹窗标题和底部按钮固定，内容区域可滚动
- 写操作弹窗有"确定"和"取消"按钮，提交时按钮显示加载状态防止重复提交
- 只读模式弹窗仅有"关闭"按钮，表单字段禁用

#### 4.3 操作反馈

- 所有写操作成功后显示成功提示
- 所有错误显示具体错误信息
- 网络错误显示"网络连接失败，请检查网络设置"
- 删除操作需二次确认

### 5. 数据模型

#### 5.1 产品表（products）
- 主键：id
- 唯一约束：code（产品编号）
- 状态枚举：Pending（待定）、Effective（在售）、Obsolete（下架）
- 同步字段：syncMainland、syncOverseas、mainlandAlertValue、mainlandStatus、overseasAlertValue、overseasStatus
- 时间戳：createdAt、updatedAt

#### 5.2 试剂表（reagents）
- 主键：id
- 外键：productId → products.id
- 状态枚举：同产品

#### 5.3 试剂库房表（reagent_warehouses）
- 主键：id
- 外键：reagentId → reagents.id（级联删除）
- 字段：warehouse、itemNo、kingdeeCode

#### 5.4 试剂同步配置表（reagent_sync_configs）
- 主键：id
- 外键：reagentId → reagents.id（级联删除）
- 唯一约束：(reagentId, system)
- 字段：system（mainland/overseas）、alertValue、warehouse、kingdeeCode、localName、status

### 6. API 接口

#### 6.1 产品接口（9 个）
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/products | 产品列表（支持 category、system 筛选） |
| GET | /api/products/:id | 产品详情 |
| POST | /api/products | 新增产品 |
| PUT | /api/products/:id | 更新产品 |
| DELETE | /api/products/:id | 删除产品（级联删除关联试剂） |
| POST | /api/products/:id/publish | 产品上架 |
| POST | /api/products/:id/offline | 产品下架 |
| PUT | /api/products/:id/sync | 更新同步配置 |
| POST | /api/products/:id/sub-publish | 子系统上架 |
| POST | /api/products/:id/sub-offline | 子系统下架 |

#### 6.2 试剂接口（9 个）
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/reagents | 试剂列表（支持 system 筛选） |
| GET | /api/reagents/:id | 试剂详情 |
| POST | /api/reagents | 新增试剂 |
| PUT | /api/reagents/:id | 更新试剂 |
| DELETE | /api/reagents/:id | 删除试剂 |
| POST | /api/reagents/:id/publish | 试剂上架 |
| POST | /api/reagents/:id/offline | 试剂下架 |
| PUT | /api/reagents/:id/sync | 更新同步配置 |
| POST | /api/reagents/:id/sub-publish | 子系统上架 |
| POST | /api/reagents/:id/sub-offline | 子系统下架 |

### 7. 非功能需求

- 统一 API 响应格式：`{ success: boolean, data?: T, error?: string }`
- 请求校验：必填字段、枚举值、类型检查
- 错误处理：400（校验错误）、404（资源不存在）、409（编号冲突）、500（服务器错误）
- 数据持久化：PostgreSQL 云数据库
- 部署：Railway 平台，自动部署
